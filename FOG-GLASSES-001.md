# FOG-GLASSES-001 — executable fog glasses

Status: experimental / noncanonical

## Purpose

Make unresolved structure perceivable and investigable without converting uncertainty into a scalar confidence score or a selected belief.

## Primitive distinction

Fog is not a wall.

A wall says traversal is unavailable.
Fog says traversal may remain available while observation is locally degraded, conflicted, incomplete, misleading, low-resolution, or outside the present instrument set.

## Fog vector

An address may carry several dimensions at once:

- density — how much unresolved material occupies the address
- grain — the scale of unresolved structures
- composition — missing, conflicting, indiscernible, outside-model, provenance-broken, etc.
- depth — how many evidentiary layers the fog spans
- response — which lamps affect it
- motion — how the fog changes through time
- persistence — how often it recurs
- origin — world / instrument / observer / model / question / receipt field / unknown

None of these fields grants probability or truth.

## Caddy contract

The Lamp Caddy may:

- preserve live candidate identities
- show which distinctions currently fail
- expose receipt failures and provenance gaps
- suggest lamps that are declared capable of distinguishing relevant candidate pairs
- record cost, prerequisites, risks, and prior response
- let a human choose or invent a lamp
- record illumination deltas

The Lamp Caddy may not:

- select a belief
- convert candidate count into probability
- silently rank candidates
- treat persistent fog as fundamental mystery
- treat intuition as evidence

## Intuition

Intuition is modeled as `selection_origin: intuition` for a lamp choice.

It can route attention or select a probe. Its value is judged only by later receipts: what changed, what failed, and what new fog appeared.

## Lens contract

A lamp asks: **what operation interrogates the evidence?**

A lens asks: **how should the resulting state be experienced?**

The initial lenses are software-native translations of AR/VR/optometry ideas:

- overlay lens: augment the current artifact without replacing it
- spatial lens: turn relation structure into navigable space
- optometry lens: compare two ways of seeing the same state
- raw lens: reveal the underlying receipt/candidate data

No headset integration is implied. Future hardware would only be another renderer of the same lens contract.

## Core loop

FOG ADDRESS
→ LIVE CANDIDATES
→ RECEIPT FIELD
→ AVAILABLE LAMPS
→ ANGLE
→ LENS
→ ILLUMINATION
→ DELTA
→ RECEIPT

Then repeat.
